abstract: "Proposes Question-gated LoRA Memories for Context Internalization, improving hypernetwork-based context internalization for LLMs. Keeps contextualization question-agnostic while making memory reading query-dependent via a lightweight question module that produces gates over chunk-level LoRA memories. Uses dual-branch objective, reasoning-aware distillation, and complementary evidence training to improve the model's ability to preserve structured information and selectively use it for future queries."
