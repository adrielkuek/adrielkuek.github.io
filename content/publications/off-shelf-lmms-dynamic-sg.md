abstract: "Revisits Dynamic Scene Graph Generation (DSGG) from task setup and model design perspectives. Identifies two limitations of the recall-oriented evaluation protocol and introduces four additional metrics for comprehensive evaluation. Explores directly using MLLMs for scene graph generation with three design changes: top-down reason-then-locate strategy, Temporal Relation Set prediction, and Importance-Aware Finetuning. Achieves state-of-the-art performance on Action Genome, VidVRD, and PVSG."
